In 2026, Flexii (an on-demand work-matching platform operating in Hong Kong, Singapore, and Taiwan) is scaling its mission to "unlock people's potential" through flexible work. We’re searching for a Data Analyst who can Boost🚀 Flexii’s growth to the next level. About the Role We are a fast-growing startup building a part-time worker matching platform that connects employers via a web portal and workers via a mobile app. As we scale user activity, matching quality, and operational insights, we're looking for a versatile Data Engineer / Analyst to own our end-to-end data capabilities. This is a hybrid hands-on role combining data and data. You'll work closely with our frontend, backend, and product teams in a collaborative startup environment, helping drive product improvements and business decisions through data. Key Responsibilities Data Analysis & Modeling Perform exploratory data analysis to uncover insights on user behavior, retention, churn, worker/employer satisfaction, and platform economics, etc. Create dashboards/reports in Looker Studio (or similar tools like Tableau/Power BI if needed) to track KPIs and support product/operations decisions. Build and iterate on scoring models using NLP techniques, embeddings/vector models (e.g. text similarity for job-worker fit, review sentiment), and machine learning to improve our service quality. Evaluate results from A/B tests or quasi-experiments to measure impact of product changes (e.g. new matching algorithms, UI tweaks). Translate business questions into data queries and deliver clear, actionable recommendations to product, operations, and leadership teams. Data Infrastructure & Engineering Design, build, and maintain scalable ETL/ELT pipelines to collect, clean, and transform data from our web portal, mobile app, APIs, and other sources into a reliable data warehouse. Manage and evolve our data warehouse primarily in Google BigQuery, including schema design, partitioning/clustering for cost/performance, and migration toward hybrid SQL/NoSQL setups for growing analytical workloads. Implement data quality checks, monitoring, and alerting to ensure trustworthy data for analysis and product features. Facilitate the setup of data tracking (event logging, user behavior, matching events) using tools like Google Analytics, custom event tracking, or similar. Collaborate with backend engineers on data-related topics (e.g. API instrumentation, database optimization in PostgreSQL, planning for NoSQL adoption like Bigtable and/or MongoDB). Additional Scope (as the data function grows) Support data needs for product experimentation and growth initiatives. Document data models, pipelines, and business logic for team knowledge sharing. Stay up-to-date with new data tools and best practices; suggest improvements to our stack as we scale. Help define data governance basics (e.g. access controls, PII handling) in a startup context.
